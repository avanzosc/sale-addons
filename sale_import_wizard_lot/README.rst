======================
Sale Import Wizard Lot
======================

This module extends the sale order import wizard to support lot selection
on sale order lines. 

When importing a sale order file, the wizard reads the lot name from the
``Lote`` column, validates that the lot exists in Odoo for the given product,
and assigns it to the resulting sale order line.
