=========================================
Website Sale Free Qty Virtual Available
=========================================

* Adds a new **Use Virtual Stock** option in website sale product configuration.
* When enabled, website stock availability is calculated using forecasted stock
  instead of available stock.
* Limits cart quantities according to forecasted stock, even if
  **Continue selling when out-of-stock** is enabled.
* Shows **Show Available Qty** option only when virtual stock mode is enabled.
