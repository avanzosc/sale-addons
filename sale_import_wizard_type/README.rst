=======================
Sale Import Wizard Type
=======================

This module extends the sale order import wizard to automatically assign a **Sale Order Type** when importing sale orders. When a warehouse is selected in the import wizard, the module looks up the corresponding sale order type and pre-fills it. The resolved type is then applied to every sale order created during the import process.
