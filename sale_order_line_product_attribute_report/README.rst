========================================
Sale Order Line Product Attribute Report
========================================

* Adds an OEM product attribute PDF report to quotations and sales orders.
* Prints one product attribute sheet for each sales order line.
* Shows customer, order, transfer graphic, shape, ply composition and finish
  information.
* Reuses the Odoo 12 OEM sheet layout as the initial report template.
