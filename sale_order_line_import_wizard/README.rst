=====================
Sale Order Line Import Wizard
=============================

* Imports product configurations from an Excel file into an existing
  quotation.
* Validates every Excel row before creating configured variants and quotation
  lines.
* Keeps the imported file, validation status, errors and generated quotation
  lines traceable from the quotation.
